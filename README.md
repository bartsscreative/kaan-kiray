Bartss Creative Studio tarafından hazırlanan Türkçe statik tasarım demosu. HTML, CSS ve tarayıcının JavaScript API’leri kullanılır. Derleme gerekmez.

## Önizleme

- [Yerel önizleme](http://127.0.0.1:8769/kaan-kiray/)

Başka bir yerel sunucuda çalıştırmak için bu klasörün içeriğini sunucunun `kaan-kiray/` yolu altında servis edin.

## Yayın

Repository `bartsscreative/kaan-kiray`. GitHub Pages kaynağı `main` dalının kökü. `.nojekyll` ve `noindex, nofollow` işaretlemesi korunur. Arayüz dosyaları göreli yollar kullanır. Open Graph görseli için canlı adres kullanılır.

Yerel teslimde QA kayıtları `GELISTIRME_DURUMU.md`, firma teyitleri `FIRMA_TEYIT_LISTESI.md`, dağıtım arşivi `release/kaan-kiray-v2.0.zip` dosyasındadır.
